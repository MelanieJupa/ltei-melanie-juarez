## 🚀 Despliegue

El sitio se despliega automáticamente desde la rama `master` usando **GitHub Pages**.

Para actualizar:
```bash
git add .
git commit -m "Descripción del cambio"
git push
```

Los cambios se reflejan en ~1 minuto en las URLs públicas.
