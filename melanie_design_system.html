01 / OVERVIEW

Mi identidad visual está inclinada a diseño con carácter, con composiciones experimentales, gran uso de ilustración, contrastes y recursos visuales fuertes. Con una estética contemporánea donde una paleta de color en escalas de grises y negros con acentos azules y verdes conviven en un mismo formato.

Mi estilo es maximalista, con elementos mezclados entre lo ornamental y lo tribal, con muchas referencias a estrellas, siguiendo las estéticas edgy, gótico y Y2K.

04 / LAYOUT

Mi sistema de espaciado busca mantener una composición dinámica, experimental y maximalista, sin perder claridad ni jerarquía visual. Combina espacios contenidos con zonas de mayor amplitud para generar contraste.

El ancho máximo del contenido es de 1440px. El espaciado no sigue una distribución completamente uniforme: puede utilizarse expresivamente para generar tensión, movimiento y jerarquía. Los elementos que pertenecen a un mismo grupo mantienen una separación consistente.

Desktop · 14 columnas

1024–1439px. Estructuras asimétricas y combinaciones de diferentes tamaños.

Tableta · 10 columnas

Móvil · 6 columnas

320–599px. Márgenes reducidos, estructura principalmente vertical.

05 / PROFUNDIDAD

La profundidad no se genera mediante blur, sombras difusas o tratamientos tridimensionales, sino mediante contraste de color, escala, superposición, posición y jerarquía.

Sombras: permitidas únicamente en imágenes, botones, tarjetas u otros elementos que requieran diferenciarse visualmente del fondo. Deben ser definidas y nítidas.

Prohibido: sombras en textos, brillos, efectos 3D, blur y sombras excesivamente suaves.

Profundidad decorativa: superposición de ilustraciones, estrellas, gráficos y recursos ornamentales manteniendo una estética plana, gráfica y contemporánea.

06 / FORMAS

Las formas utilizadas en la identidad son predominantemente geométricas, gráficas y de bordes rectos. Las esquinas deberán permanecer rectas y no se utilizarán bordes redondeados en botones, tarjetas, campos, imágenes u otros componentes.

Los elementos circulares pueden utilizarse como recursos gráficos o decorativos, pero no deberán interpretarse como un tratamiento de redondeado de los componentes de interfaz.

08 / REGLAS

✓ Do's

  • Usar {colors.primary} como color principal para títulos y elementos de mayor jerarquía.
  • Usar {colors.secondary} para subtítulos, categorías, estados activos y énfasis sobre fondos claros.
  • Usar {colors.secondaryOriginal} solo sobre fondos oscuros.
  • Usar {colors.surface} para textos sobre fondos oscuros y pequeños acentos.
  • Mantener Open Sauce Two para cuerpo y contenidos de lectura.
  • Usar Oscine Trial para navegación, categorías, botones, etiquetas y subtítulos.
  • Usar Gill Sans Display para títulos y mensajes de mayor impacto.
  • Mantener una estética plana, geométrica y de alto contraste.
  • Usar esquinas rectas de 0px.
  • Permitir composiciones asimétricas y ornamentales cuando refuercen el carácter experimental.
  • Implementar hover mediante cambios de color y escala.

✕ Don'ts

  • No utilizar colores cálidos ni opacos.
  • No combinar colores de manera que reduzcan el contraste o dificulten la lectura.
  • No utilizar tipografías fuera de Gill Sans Display, Oscine Trial y Open Sauce Two.
  • No usar botones circulares, de píldora o con esquinas redondeadas.
  • No usar bordes redondeados en tarjetas, imágenes, campos o contenedores.
  • No usar sombras difusas, glows, blur o efectos excesivamente tridimensionales.
  • No usar sombras como recurso principal para crear jerarquía.
  • No usar efectos 3D o sombras en textos.
  • No usar tipografías serif dentro de la jerarquía principal.
  • No reducir el cuerpo de texto por debajo de 16px.
  • No usar texturas o imágenes de fondo que compitan con la información principal.
  • No esconder información o navegación esencial para conservar una composición.
  • No sacrificar legibilidad por una composición maximalista.
  • No usar secondaryOriginal ni surfaceVariantOriginal sobre fondos claros.
